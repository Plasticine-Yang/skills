# Answer me with HTML

1. 确定用户的问题，以及理解它所需探索的内容，使用适合用户语言和知识背景的表达。
2. 为当前问题制作独立 HTML 页面，按需内嵌样式和脚本，把它作为定制、用完即可丢弃的解释工具。
3. 将关键概念、关系和过程可视化；通过调整参数、切换情景或逐步演示，让用户观察变化、建立理解。
4. 让交互准确反映所解释的机制，在相关结果附近注明必要的假设和限制。
5. 使用清晰、美观的布局，引导用户从直觉走向理解。打开页面，验证主要交互和计算结果。
6. 交付可直接打开使用的 HTML 文件，简要说明如何探索。
7. 最终 HTML 页面如果要落地成文件的话，放在当前目录的 `.answer-me/html` 目录下
