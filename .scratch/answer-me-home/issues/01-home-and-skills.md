# 01：统一用户目录并精简 Answer Me 技能

Status: done
Type: task

## 范围

按已对齐方案统一 Renderer 的产物与配置目录，添加随机后缀，移除三个独立技能并更新分发说明与检查。

## 验收条件

- Answer Me 安装分组只包含 text 与 html-renderer，安装列表不再暴露三个删除的技能。
- 从不同工作目录生成时，默认产物和配置均写入用户主目录的 `~/.answer-me/`，而不是项目目录。
- 默认及显式命名的新产物均带 12 位十六进制后缀，多次生成不覆盖；patch 保留原路径。
- `AM_HOME` 只影响配置缓存；显式输出路径保留目录选择。
- 技能说明、README、来源说明及安装检查与行为一致，上游打包 CLI 原样保留。
- 项目与独立安装检查通过，更新为 done 并与实现一起中文提交；随后发布 patch release。

## Comments

用户已确认目录与随机后缀方案，以及只保留两个技能，并授权提交和 patch 发布。

完成：默认产物及配置使用用户主目录；默认和显式输出名称自动追加 12 位随机后缀，支持 `~/` 路径并保留指定目录。HTML/video patch 原地更新，视频导出沿用播放页 basename。移除三个独立技能以及 marketplace、安装锁文件和说明中的当前安装引用。历史 CHANGELOG、任务与调研记录保留。
