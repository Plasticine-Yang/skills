# 渲染器同步与发布

将 HTML renderer 从上游 0.4.3 升至正式发布 v0.4.9，保留本地名称、显式调用、目录隔离和更新渠道。建立可重复调用的 `sync-html-renderer` skill，默认同步上游最新正式 release，并通过现有发布入口完成仓库 patch release。

调用同步 skill 即授权本次同步、验证、中文提交和 patch 发布。没有新版本且没有待发布同步时结束，不制造空发布。上游说明及依赖变化由 agent 合并；确定性脚本处理版本选择、缓存、校验和、原样文件同步和来源记录。失败后保留已完成工作，修复原因并复用发布状态继续。

验收：新旧 CLI 兼容、独立安装检查、浏览器布局检查、新脚本可重复运行且保护本地改动；新 skill 可安装并显式调用；正式 Release 可访问且 tag 对应版本 PR 的合并提交。
