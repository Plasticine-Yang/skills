# Domain Docs

<!-- setup-project:domain:start -->
探索代码时，先查阅已有的领域词汇和相关架构决策。

- 默认使用根目录 `GLOSSARY.md` 与 `docs/adr/`。
- 已有 `GLOSSARY-MAP.md` 时，按它读取相关上下文的 glossary，并查阅已有上下文 ADR 目录。
- 项目已经配置的其他路径和上下文布局继续使用，在本文档保留明确的读取指针。

这些文件不存在时继续工作。由 domain-modeling 在术语或决策明确后按需创建，初始化不预先创建空 glossary 或 ADR。

在 ticket、研究结论、代码建议和测试中使用 glossary 已定义的术语；遇到空缺时记录给 domain-modeling。建议与既有 ADR 冲突时指出具体 ADR 和理由，保留项目决策的上下文。
